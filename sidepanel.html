How to update the script (when the bot says it's old)
  1. Open the Google Sheet whose Extensions › Apps Script made the web app link above (the link starts with the same …/macros/s/…).
  2. In the editor: select everything (Ctrl+A), delete, paste the whole ShipCube Sheet Script.gs.txt from the ShipCube Bot v2 folder. Click 💾 Save.
  3. Deploy › Manage deployments › click the ✎ pencil › Version: New version › Deploy. (Saving alone is not enough, and “New deployment” would make a NEW link.)
  4. Allow the permissions if Google asks, then click Test connection here — it should say script v11.
